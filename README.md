# Astra

Astra is a native, scriptable code editor being implemented against [EditorDoc.md](EditorDoc.md).
The production stack is C++ / xmake / SDL3 / Skia Graphite / Dawn / QuickJS-NG / libuv.

This repository is under active construction. See [implementation status](docs/STATUS.md)
for completed acceptance checks and outstanding work. It is not yet a production release.

## Development

Read [AGENTS.md](AGENTS.md) before contributing. Development and validation in this checkout
target Windows; macOS and Linux validation requires their respective native environments.

Pinned tools and build commands are documented in [BUILD.md](docs/BUILD.md).
