# Astra icon attribution

UI graphics: Microsoft and vscode-codicons contributors, from
https://github.com/microsoft/vscode-codicons . Artwork is licensed under
Creative Commons Attribution 4.0; the upstream license also records the
Git-logo exception. Code has a separate MIT license. Both notices are shipped
under licenses/icons/codicons/.

File, language and folder graphics: Material Extensions and Material Icon Theme
contributors, from https://github.com/material-extensions/vscode-material-icon-theme .
The official material-icon-theme 5.39.0 published assets and association metadata
are used under its MIT license, shipped under licenses/icons/material/.

Checked-in SVGs are unchanged upstream files. Build-time adaptation sets a
common viewport; monochrome UI graphics receive the current Astra theme color.
The imported association subset retains basename/extension/folder matches;
path-specific patterns, extension-host code and previews are excluded.

provenance/icons.json records source commits/releases, artifact hashes and
the complete resource inventory. This notice is included in every installation.
